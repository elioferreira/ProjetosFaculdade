# Saúde Conectada: Compartilhamento Seguro de Dados Essenciais do Paciente

## 📋 Sobre o Projeto
Projeto Integrador II - ADS - Unilasalle - 2026/2
Professor: Fabiano Silva da Silva

Solução simulada para compartilhamento de dados essenciais de saúde
entre instituições, visando segurança e acurácia no atendimento.

## 🎯 Objetivo
Simular um portal onde o paciente autoriza o compartilhamento de um
resumo essencial da saúde (alergias, doenças crônicas, medicamentos,
exames recentes) entre instituições de saúde, via QR Code ou login único.

## 🧩 Problema
Dados de saúde fragmentados em sistemas que não se comunicam
(e-SUS, PEC, TASY, TOTVS), gerando risco de erros clínicos.
