# Planejamento do Projeto

## Cronograma de execução
- Semana 1: Formação do grupo e definição do tema
- Semanas 2-3: Pesquisa dos sistemas de saúde
- Semanas 3-4: Mapeamento do fluxo atual de dados
- Semanas 5-6: Coleta de dados (públicos/fictícios)
- Semanas 7-8: Análise dos dados
- Semanas 9-10: Proposta de melhorias
- Semanas 11-13: Desenvolvimento da simulação
- Semanas 14-15: Avaliação e validação
- Semanas 16-17: Redação do relatório final
- Semana 18: Apresentação e entrega

## Detalhamento das atividades
1. Definição do foco do projeto.
2. Levantamento dos sistemas (e-SUS, PEC, TASY, TOTVS).
3. Descrição do fluxo de dados e pontos de fragmentação.
4. Obtenção de dados públicos/fictícios.
5. Identificação de incompatibilidades.
6. Definição dos dados essenciais e ferramentas.
7. Criação de telas e protótipos.
8. Definição de métricas (acurácia, satisfação, tempo).
9. Elaboração do relatório com evidências.
10. Preparação dos slides finais.
